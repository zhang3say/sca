01主流 6 大生态源码依赖解析规则与头号暗坑速查表

语言生态 清单 vs 确定性锁/真源 冲突裁决算法 共存语义 头号红线暗坑与 Layer 1 铁律
Java · Maven pom.xml（无锁；靠 Effective POM / dependency:tree） Nearest Definition（最短路径优先）+ 同深 First Declaration；dependencyManagement / BOM 优先级最高。 单版本（同一 Classpath 仅存 1 份） 严禁用版本号大小猜结果；不展开父 POM ${var} 与 <scope>import</scope> BOM 必算错版本。
Java/Kotlin · Gradle build.gradle(.kts) / libs.versions.toml + 可选 gradle.lockfile 默认 Highest Version Wins；支持 strictly/约束干预；按 Configuration 独立求解。 单版本（按 Configuration 隔离） 与 Maven 规则完全相反；无锁动态范围（31.+）与图灵完备 DSL 只能靠 CI Hook/ORT/沙箱还原。
JS/TS · npm / pnpm package.json + package-lock.json v3 / pnpm-lock.yaml 子树嵌套共存；npm 做 Hoisting 提升；pnpm 用 importers + snapshots 软链隔离。 多版本合法共存（按路径区分实例） 必须在 L2 IR 按 install_subpath 保留独立 bom-ref；警惕 npm 幽灵依赖与 Monorepo workspace:*。
Python · PyPI / uv pyproject.toml / requirements.txt + uv.lock / poetry.lock / pylock.toml PubGrub/回溯求解器；通用锁文件附带 PEP 508 Environment Markers 条件分支。 单版本（同一 Python 环境仅存 1 份） 不求值 Markers 会爆跨平台误报；严禁在工作节点裸跑 setup.py（解析元数据即触发 RCE）。
Go · Modules go.mod（真源）+ vendor/modules.txt（注：go.sum 非锁） MVS（Minimal Version Selection）：取满足全部上游下界的最低版本，不自动升最新。 主版本独立（/v2 视为不同包名） go.sum 是 append-only 校验日志！拿 go.sum 当锁文件必爆大规模 Ghost CVE 误报。
Rust · Cargo Cargo.toml + Cargo.lock（官方确定性锁文件） SemVer 兼容范围内尽量共享新版，不兼容主/零号次版本（0.x）可并存；支持 Feature 条件剪枝。 不兼容版本可多版本并存 二进制优先用 Cargo.lock（应用）或 cargo-auditable 嵌入段；注意平台/Feature 开关引入的条件依赖。

04ACL 反腐败契约与多提取器置信度融合 4 条铁律

1. ACL 翻译边界：绝不泄漏第三方私有结构

Syft *sbom.SBOM、OSV-SCALIBR Inventory、cdxgen JSON 与 ORT OrtResult 必须在 Layer 1 出口经无状态适配器统一转化为内部 RawExtractionEnvelope，并穿越 Canonicalizer 后再进入融合引擎。

2. 单版本生态：高阶覆写低阶（Supersede）

Java / Python / Go 等单版本作用域内，同一 (project_root, base_purl) 按 Tier 4 (0.98) ≈ Tier 3 (0.95) > Tier 1 (0.92) > Tier 2 (0.82) > Tier 0 (0.45) 裁决；低阶猜测标记 superseded 记入 CycloneDX 1.7 citations[]，绝不并存。

3. 多版本生态：按 (purl, install_subpath) 分治

npm / pnpm 允许嵌套多版本合法共存。只有完整 PURL 与安装子路径均一致时才合并证据；不同路径实例在 Layer 2 IR 保持独立 snapshot_nodes (bom-ref)，防止漏洞版本被根路径版本吞掉。

4. 异构资产域：互补并集 + 最细边富化

OS 包（deb/rpm）、语言应用包（pypi/maven/npm）与 AI 模型属互补域，执行并集；同一节点被多高阶引擎同时命中时，保留最精细的带 Scope 有向边（如 ORT runtime/test）并合并 occurrences[]。

OCI 容器分层树 manifest.json → diff_ids → layer.tar.gz；.wh.<file> 与 .wh..wh..opq stereoscope (Apache-2.0) 用户态内存 VFS 合成 SquashedScope；历史删除层仅归档审计。 严禁 docker exec 与宿主机内核 mount -t overlay；默认告警严禁扫无隔离的 AllLayers。
Debian / Distroless / Alpine /var/lib/dpkg/status、status.d/*、/lib/apk/db/installed、os-release 过滤 installed 状态；必抓 Source（deb）与 o: origin（apk）写入 PURL upstream，os-release 写入 distro。 Distroless 无 /var/lib/dpkg/status 总表且无 shell；丢弃 upstream 或 distro 将直接击穿 L3 Backport 匹配。
RHEL / Fedora / SUSE RPM /var/lib/rpm、/usr/lib/sysimage/rpm（Packages / Packages.db / rpmdb.sqlite） go-rpmdb（MIT，纯 Go 零 CGO）自动识别 BDB/NDB/SQLite 三代 DB 并提取 SourceRPM。 RHEL 9+ 弃用 BDB 改用 rpmdb.sqlite；禁止 Worker 通过 CGO 硬绑宿主机 librpm.so。
Java JAR / Fat-JAR / Shade BOOT-INF/lib/*.jar、META-INF/maven/**/pom.properties 受限内存流式递归提取 nested JAR；Shade Uber-JAR 结合字节码指纹提示与 CI 前置 Tier 3 BOM 按 SHA-256 融合。 防 Zip Bomb 必须强制设最大递归深度 + io.LimitReader + ZipSlip ../ 过滤；Shade 会重定位类路径并剥离元数据。
