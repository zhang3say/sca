018 层产品域核心实体与不可变性字典（Lesson 0023）

实体对象 核心主键 / 唯一定位 生命周期与不可变规则 关键隔离与反模式红线
Tenant / Workspace tenant_id (UUIDv7)
workspace_id		 SaaS 多租户根与业务域边界；私有化单租户固定默认 tenant_id。 全表从第一天保留 tenant_id，禁止为私有化删字段分叉 Schema。
Project & Asset project_id（业务组）
asset_id (kind, locator)		 Project 挂 Backstage Owner 与 KPI；Asset 区分源码/镜像/AI 模型/MCP。 禁止把整个 Monorepo 当作唯一扫描粒度，必须拆出异构 Target。
Snapshot snapshot_id + cas_hash 严格不可变（Immutable）：固化时间点成分图、Commit/Digest。 严禁将人工豁免/审计状态直接写死在 Snapshot 行内。
LogicalFinding finding_id + 稳定位置指纹 活体状态机（OPEN/FIXED/REOPENED/SUPPRESSED/VEX_NOT_AFFECTED）。 新扫描仅刷新 last_seen_snapshot_id，夜间 0-day 可无扫描直接生成。
Waiver & ReleaseBundle waiver_id (OpenVEX)
release_bundle_id (Tag)		 Waiver 随逻辑位置继承并带到期提醒；ReleaseBundle 发版封板冻结。 发版证据包必须独立签名固化，不得随日后豁免过期或漏洞修复被覆写。
RemediationTask task_id（按 Project+升级动作聚合） 把同组件多条 CVE 合并为 1 个 PR 或 1 条 Agent 修复动作。 严禁按“1 CVE = 1 工单/1 PR”向研发刷屏。

03Go 模块化单体边界、跨语言契约与队列演进速查（Lesson 0024）

Go internal/ 包隔离		 全部控制面/Domain/L1+L3/Policy 同仓收敛；私有化单二进制极简启动，SaaS 按角色副本水平扩容。 严禁跨模块直接 JOIN 私有表；禁止在控制面跑不可信项目构建脚本。

Queue Stage 1 → 2 → 3 PG SKIP LOCKED / River (MPL-2.0) → NATS (Apache-2.0) → Kafka / Temporal (MIT) 通过抽象 ScanQueue 接口平滑替换：Day-1 用 PG 同事务入队零丢单，成长后切单二进制 NATS JetStream。 River 须守 MPL-2.0（仅直接调用不改源文件）；中小私有化不强制捆绑 Kafka。
