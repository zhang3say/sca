01四层解耦架构契约（Layer Contract）

架构层级 核心职责与输入输出契约 研发策略 典型失效模式（反模式）
Layer 4
决策与壁垒层		 静态/动态可达性、恶意包行为评分、EPSS/KEV/VEX 降噪、无破坏性升级路径、策略门禁与 AI 风险推理。
Input: L2 IR + L3 Intel + CallGraph/Runtime → Output: Actionable Finding / PR / Gate		 核心自研 把 CVSS 高危清单原样抛给研发，无可达性与修复路径，导致 90%+ 误报疲劳。
Layer 3
情报与知识底座		 多源漏洞聚合与去重（OSV/GHSA/NVD）、生态原生版本区间语义引擎、恶意包情报、许可证兼容性与包健康度。
Input: Multi-Feed Advisories → Output: Normalized OSV/Graph Query API		 开源源 + 自研管线 仅依赖 NVD CPE 字符串模糊匹配，导致大量误报/漏报与跨生态版本比较失真。
Layer 2
统一中间表示 (IR)		 全平台唯一真相源：PURL 组件主键、有向依赖图（直接/传递/Scope/证据链）、CycloneDX 1.7 兼容导入导出、预留符号/模型/VEX 挂载点。
Input: Normalized Events → Output: Canonical Component Graph		 100% 自研主权 直接将 Trivy/Syft 输出 JSON 充当核心数据库 Schema，导致更换提取器或新增可达性时推倒重写。
Layer 1
采集与提取层		 跨形态资产扫描：源码 Manifest/Lockfile、构建期依赖树、容器镜像分层、OS 包库、制品/二进制、AI 模型清单。
Input: Target Artifacts → Output: Raw Inventory + Evidence		 借力 OSS + 补齐短板 从零手写几十种语言/OS 包格式解析器消耗全部人力；或全盘透传单一 CLI 无适配器隔离。
