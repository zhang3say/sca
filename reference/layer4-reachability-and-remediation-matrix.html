01静态调用图算法光谱（CHA / RTA / VTA / 0-CFA）与四态置信度规范（Lesson 0011）

算法 / 状态级别 核心机制 / 定义条件 工程表现与精度边界 商业 SCA 门禁与 VEX 动作
CHA
（ECOOP 1995）		 仅依声明类型 + 类继承层次树连边，不校验是否实例化。 近线性 O(V + E)；多实现接口下产生大量不可执行假边。 仅作 VTA 种子初图或冷启动兜底，不可作为商业降噪卖点。
RTA
（OOPSLA 1996）		 维护全程序单一“已实例化类集合”剪除未分配类。 快但抗污染差：无关测试包或邻模块 new T() 即污染全局。 仅适单模块快扫；企业大仓库必须升级至变量级传播。
VTA
（OOPSLA 2000 · Go govulncheck）		 SSA 上建变量级类型传播图，按赋值/参数边精确追踪类型流。 商业甜点区：免疫测试包实例污染，近线性扩展，精度高。 主力算法（Go 原生 x/tools/go/callgraph/vta）。
0-CFA / k-CFA 字段敏感 / 调用上下文敏感指针分配点不动点分析。 理论精度最高；大工程易 O(n3) 超时与峰值内存爆炸。 仅配合云端库摘要按需/限深使用，禁无上限全量进 30s PR SLA。
REACHABLE
四态之一 · P0		 存在 Entrypoint → Sink（或 Trigger API / Level 1 顶层副作用）完整路径。 高置信度真阳，输出 CycloneDX 1.7 evidence.callstack.frames[]。 PR 门禁阻断 + 自动生成修复 PR（Lesson 0014）。
POTENTIALLY_REACHABLE
四态之二 · 护栏		 模块已导入（Level 1），但遇 getattr / 反射 / 动态代理 / 缺 L3 符号而断链。 严禁谎报不可达！记录 UNKNOWN_DYNAMIC / MISSING_SYMBOL_DB 原因码。 移交 Lesson 0012 运行时探针实证确认或人工安全审阅。
UNREACHABLE & UNKNOWN
四态之三/四		 UNREACHABLE：封闭静态分支已证不可达；UNKNOWN：构建/前端失败兜底。 区分“可证死代码消噪”与“解析异常”，防止工具报错被当成安全。 UNREACHABLE 自动签发 CycloneDX VEX code_not_reachable（对应 OpenVEX vulnerable_code_not_in_execute_path）消警（Lesson 0013）。

02跨语言前端、L3 符号映射、生态预计算与商用引擎选型矩阵（Lesson 0011）

域 / 语言族 推荐商用底座与许可 核心工程破局点（避坑要点） 闭源红线与架构隔离要求
Go 生态 golang.org/x/tools + x/vuln（BSD-3-Clause）；vuln.go.dev（CC-BY-4.0） go/packages → ssa → VTA；强制将 init() 与异步协程 go fn() 设为入口根节点。 直接嵌入 Go Core；复用 vuln.go.dev 符号数据须保留 CC-BY-4.0 署名。
Java / JVM OW2 ASM（BSD-3-Clause） / OPAL（BSD-2-Clause） / WALA（EPL-2.0） 基于编译 .class/.jar 分析；合成 Spring DI（@PostMapping）入口；L3 标注反序列化 Trigger API。 严禁 将 SootUp（LGPL-2.1）静态打进闭源 Fat-JAR，亦严禁内嵌 CodeQL 商用！
JavaScript / TypeScript TypeScript API（Apache-2.0）+ cs-au-dk/jelly（BSD-3-Clause） 采用 Indirection-Bounded（ECOOP 2024）穿透高阶回调；必开 Level 1 顶层导入副作用捕获恶意初始化。 独立 Node Worker 封装；Tree-sitter（MIT）不可用于跨文件 JS 调用解析。
Python PyCG（Apache-2.0）+ JARVIS（arXiv:2305.05949）按需流敏感类型图 采用应用为中心按需构图防止全依赖树卡死；遇 getattr()/eval/C 扩展触发 UNKNOWN_DYNAMIC 降级。 切勿因 PyCG ~69.9% 召回上限而把未连通路径直接标为安全豁免。
L3→L4 符号库 & 预计算拼接 Tree-sitter（MIT）做 Patch-Diff + 自研 Summary 缓存 Fix Commit AST 提符 + LLM 初筛 + 专家精校 Trigger API；云端按 (purl, version) 预计算库摘要，PR 在线仅拼接第一方。 避免在 PR 门禁重算全量 180+ 传递依赖；osv-scanner --call-analysis=rust 会执行 build.rs 须进 Tier 3 沙箱。

03运行时可达性采集光谱、静动态融合规则与容器裁剪商用红线（Lesson 0012）

维度 / 层级 选定基准与开源代表 核心裁决规则 / 工程底线 商用闭源红线与架构禁忌
四层运行时采集
（< 1%–2.5% CPU）		 Kubescape (Apache-2.0) · JFR jdk.ClassLoad · PEP 669 · NODE_V8_COVERAGE 按 image_digest 归一消费 RuntimeEvidence；JVM 用 JFR（stackTrace=false）；Python 用 PEP 669。 严禁轮询 getAllLoadedClasses() 或线上挂载 sys.settrace/全量插桩；eBPF 内核 C 须进程隔离。
静动态融合公理
（冷路径防漏报）		 Static × Runtime × Window 三维裁决矩阵 REACHABLE + NOT_OBSERVED → LATENT_REACHABLE（禁 VEX）；仅 ≥ 14d & 批处理 允许压降 OS 包。 UNREACHABLE + LOADED/EXECUTED 立即触发 STATIC_SOUNDNESS_ALERT P0 并撤回旧 VEX！
容器减面裁剪
（arXiv:2407.11259）		 Distroless / apko (Apache-2.0) · Confine seccomp · MinToolkit 构建期最小闭包（Distroless/apko）消除 85%+ OS 漏洞且保完整 SBOM；kubectl debug 兜底排障。 低覆盖率禁全自动 Mint 动态删文件防误删冷路径；严禁 把 canonical/chisel（AGPL-3.0）嵌入闭源 SaaS 后端！

04超越 CVSS：EPSS / KEV / SSVC 协同分级、三大 VEX 映射与信任撤销矩阵（Lesson 0013）

维度 / 协议层 标准规范 / 纯 Apache-2.0 底座 核心工程语义与裁决铁律 高危误区与商业闭源合规边界
威胁与优先级标尺
（非补偿融合）		 CVSS v4.0 · FIRST EPSS v4 · CISA KEV · CISA SSVC Reachability + SSVC 非补偿树（Act / Attend / Track* / Track）；KEV 是优先底线（无视 CVSS < 7.0）；每日全量同步 EPSS gzip CSV。 严禁线性加权（补偿掩蔽）；EPSS Probability ≠ Percentile 且低 EPSS 禁签 VEX；严守 FIRST ToS（保留署名、禁脱离产品转售原库）。
三大 VEX 状态与理由映射
（无损投影）		 openvex/go-vex (Apache-2.0) · cyclonedx-go (Apache-2.0) · gocsaf/csaf (Apache-2.0) 不可达：OpenVEX/CSAF 用 vulnerable_code_not_in_execute_path，CycloneDX 用 code_not_reachable；CSAF 状态带 known_ 前缀；容器子依赖必用 products[].subcomponents[]。 CycloneDX false_positive 仅限组件误识别（非不可达）；严禁把未绑定父镜像的裸三方库 PURL 写入 VEX 造成全局误消警。
VEX 信任层级与事件撤销
（Safety Floor）		 Canonical VEX Ledger + Trivy --vex / vexctl (Apache-2.0) Tier 0 Safety Floor：L4 硬可达永远驳回外部 not_affected；人工缓解强制 30–90 天 TTL；监听 CallGraph/JFR/KEV/EPSS 飙升自动撤销重算。 严禁盲信未签名社区 VEX Hub 压制可达漏洞；严禁直接物理删除历史 CVE 记录或签发永不过期的静态静默白名单。

(EMSE 2022) · japicmp/revapi (Apache-2.0) · x/exp/apidiff (BSD-3) · griffe (ISC) · cargo-semver-checks (MIT/Apache-2.0) 云端按 (purl, v1, v2) 预计算库级破坏符号，在线与 L4 第一方调用图求交：0 命中直接放行 Safe Major（Ochoa 实证仅 ~7.9% 客户端受波及）；非 0 命中精准标注 file:line。 严禁仅凭 SemVer 主版本一刀切禁升，亦禁盲信 Minor/Patch 绝对兼容（16.6% 非 Major 违规）；严防同名混淆 OpenJDK apidiff 为 GPL-2.0 + Classpath！
