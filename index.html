CH 01总体架构与开源边界（Architecture & Strategy）

拍板四层解耦契约、商业闭源协议红线与平台核心中间表示（Layer 2 IR）主权。

2 课 · 核心基石
  • 0001
    第三代 SCA 四层解耦架构与「借力 vs 自研」边界划分

    剖析“扫描器即平台”为何在 6 个月内推倒重写；建立 L1–L4 解耦契约；实测排雷 Apache-2.0/MIT 底座与 GPL/LGPL/专有规则雷区。

    全局架构 OSV-SCALIBR / Syft / cdxgen / Trivy 标杆：Snyk · Endor · Socket
    已发布 · 可学习 ~18 min
  • 0002
    统一中间表示（Layer 2 IR）设计：PURL 为何淘汰 CPE 与 CycloneDX 1.7 图模型

    深拆 ECMA-427 PURL 命名空间与限定符规范；设计双层身份组件依赖图库表（直接/传递/Scope/证据链），兼顾 CycloneDX 1.7 与 SPDX 3.0 双向投影及 VEX/可达性/AI-BOM 预留槽。

    L2 统一 IR ECMA-427 PURL · ECMA-424 CycloneDX 1.7 SPDX 3.0 · Dependency-Track v5
    已发布 · 可学习 ~20 min

CH 02多语言与全形态采集提取引擎（Layer 1 Sensors）

吃透源码/构建/镜像/制品采集的真实失真点，设计「开源库嵌入 + 隔离沙箱 + 自研补强」的插件化采集架构。

4 课 · L1 引擎
  • 0003
    源码依赖解析的底层真相：Manifest、Lockfile 与构建期解析陷阱

    拆解 Maven BOM/依赖调解、Gradle 动态配置、npm workspaces、Python uv/Poetry 与 Go MVS 的版本裁决差异；厘清静态解析精度天花板与构建期沙箱防 RCE 隔离边界。

    L1 采集提取 Maven / npm / PyPI / Go 构建期沙箱安全
    已发布 · 可学习 ~20 min
  • 0004
    开源提取底座源码级拆解：OSV-SCALIBR、Syft、cdxgen 与 ORT 组合编排

    对照四大 Apache-2.0 引擎的插件接口与能力互补矩阵；设计反腐败适配器（Adapter）与多提取器置信度融合消歧算法，避免重复造轮子又保住核心掌控力。

    L1 采集提取 OSV-SCALIBR · Syft · cdxgen · ORT 多源证据融合
    已发布 · 可学习 ~20 min
  • 0005
    容器镜像、OS 发行版与制品分层采集原理

    剖析 OCI 镜像分层与 Whiteout 删除语义、dpkg/rpm/apk 数据库解析、Distroless 无包管理器镜像识别，以及 Java Fat-JAR / Uber-JAR 与 Go/Rust 静态编译符号段提取。

    L1 采集提取 OCI Layers · Stereoscope · go-rpmdb 镜像 & 制品
    已发布 · 可学习 ~18 min
  • 0006
    高并发多触点采集架构：IDE、PR 门禁、CI 流水线与异步持续重算

    打通开发者本地、PR 增量 Diff 扫描、CI 缓存加速与服务端“一次采集、持续重算”事件流水线（深度借鉴 OWASP Dependency-Track 与 Snyk 工作流架构）。

    L1 + 全局 Dependency-Track · 增量 Diff 多触点体验
    下一课 · ZPD ~18 min

CH 03漏洞情报底座与精确匹配引擎（Layer 3 Intelligence）

构建超越 NVD 的高准确度多源情报管线、生态原生版本比较引擎、离线分发包与许可证合规推理内核。

4 课 · L3 情报
  • 0007
    OSV Schema 与多源漏洞汇聚去重架构（OSV / GHSA / NVD / 发行版）

    吃透 ossf/osv-schema 结构与 CVE/GHSA/OSV 别名图谱归一化；解决 NVD 滞后、字段污染与多源冲突裁决问题，参考 Google deps.dev 与 Snyk 情报研判管线。

    L3 情报引擎 OSV Schema · deps.dev · GHSA 标杆：Snyk VulnDB
    规划中 ~20 min
  • 0008
    生态原生版本区间语义引擎：SemVer、Maven、PEP 440、Debian EVR 与 VERS

    剖析跨生态版本排序规则的暗坑（预发布标签、Epoch、Maven 限定符），重点拆解 Debian/RHEL 发行版安全回溯补丁（Backport Patch）导致的经典误报成因与消除算法。

    L3 情报引擎 VERS 规范 · Backport 消误报 核心自研算法
    规划中 ~20 min
  • 0009
    离线/私有化漏洞库分发、增量更新与高并发匹配索引设计

    拆解 Trivy OCI/BoltDB 与 Grype SQLite 本地库架构；设计基于 PURL 前缀与版本区间的内存/倒排索引，实现万级组件毫秒级匹配与内网断网环境的安全增量同步。

    L3 情报引擎 Trivy DB · Grype DB · OCI 分发 离线私有化
    规划中 ~18 min
  • 0010
    开源许可证合规引擎与传染性兼容性推理

    实现 SPDX 表达式语法树求值（AND / OR / WITH 异常处理）、基于分发形态与链接方式的传染性策略矩阵、ScanCode 双许可合规集成与合规 Notice 自动生成。

    L3/L4 合规 SPDX Expression · ORT · ScanCode 传染性推理
    规划中 ~18 min

CH 04可达性分析、智能降噪与安全修复（Layer 4 Core Moat）

用静态调用图、运行时上下文、EPSS/VEX 与无破坏性升级求解器，把传统 SCA 90%+ 的告警噪音压成开发者愿意修的精准清单。

4 课 · L4 核心壁垒
  • 0011
    静态函数级可达性（Call Graph）底层原理与跨语言工程挑战

    拆解 CHA / RTA / 指针分析精度与性能权衡；逐语言解析 Java 字节码、Go SSA、JS/Python 动态派发难点，以及 L3 漏洞函数级符号指纹如何驱动调用路径剪枝。

    L4 核心壁垒 Call Graph · AST/SSA/Bytecode 标杆：Endor Labs
    规划中 ~20 min
  • 0012
    动态运行时可达性与容器裁剪：用真实执行上下文击穿误报

    对比静态分析盲区（反射/DI 框架/容器冗余 OS 包）与运行时探针（JVM 类加载、eBPF/文件系统访问跟踪）；设计「静态 + 动态」融合置信度判定模型。

    L4 核心壁垒 Runtime Context · 静动态融合 标杆：Wiz / Endor
    规划中 ~18 min
  • 0013
    超越 CVSS：EPSS、CISA KEV 与 VEX（OpenVEX / CycloneDX / CSAF）协同降噪

    构建多维度优先级评分模型（可达性 × EPSS 在野利用概率 × KEV × 业务暴露面）；落地标准 VEX 四态工作流与理由码，实现可审计、跨团队流转的误报豁免闭环。

    L4 降噪 FIRST EPSS · OpenVEX · CSAF · CycloneDX VEX
    规划中 ~18 min
  • 0014
    无破坏性自动修复与升级路径求解器（Guided Remediation）

    研究 Google OSV-Scanner v2 Guided Remediation 与 Snyk 修复图谱；基于依赖图与版本区间约束求解“最小破坏性升级路径”，结合 API 变更检测自动发起安全 PR。

    L4 自动修复 OSV-Scanner v2 · 约束求解 标杆：Snyk PR
    规划中 ~20 min

CH 05投毒防御、同源检测与 AI 时代供应链安全（Malware, Binary & AI-BOM）

补齐商业闭环中“无 CVE 威胁”与“无清单代码/二进制”盲区，并率先抢占大模型与 Agentic AI（MCP/Skills）供应链安全新高地。

5 课 · 前沿壁垒
  • 0015
    恶意包与供应链投毒检测引擎（对标 Socket.dev）

    冷启动集成 ossf/malicious-packages；设计包发布实时流分析架构、AST 静态行为红旗规则（网络外联/读 .env/postinstall/混淆）、包名抢注与维护者接管异常检测。

    L3/L4 投毒防御 ossf/malicious-packages · AST 行为 标杆：Socket.dev
    规划中 ~20 min
  • 0016
    开源代码片段同源检测与无源码二进制 SCA 底层原理

    拆解源码复制粘贴（Copy-Paste）的抗修改哈希指纹（Winnowing / Token / AST 特征）与 C/C++ 无源码二进制（字符串常量/导出符号/函数 CFG 特征）的大规模指纹库架构。

    L1/L3 同源检测 Snippet Fingerprinting · Binary SCA C/C++ 与黑盒制品
    规划中 ~20 min
  • 0017
    AI-BOM 统一建模：模型权重、数据集与推理框架血缘（CycloneDX ML-BOM / SPDX 3.0）

    对齐 OWASP LLM03，在现有 Layer 2 统一图谱上扩展基座模型、LoRA 适配器、训练数据集与推理框架（PyTorch/vLLM/ONNX）血缘关系及模型许可证风险识别。

    AI 供应链 CycloneDX ML-BOM · SPDX 3.0 AI Profile OWASP LLM03
    规划中 ~18 min
  • 0018
    模型序列化安全与恶意载荷扫描（Pickle RCE vs Safetensors）

    剖析 .pkl/.pt/.ckpt 反序列化字节码注入执行原理，学习 safetensors 零代码执行机制与 Protect AI ModelScan 静态操作码检测范式，设计模型制品门禁扫描器。

    AI 供应链 Pickle Opcodes · Safetensors · ModelScan
    规划中 ~18 min
  • 0019
    Agentic AI 与 MCP 服务器供应链治理（OWASP ASI04）

    直面 AI Agent 时代新攻击面：第三方 MCP Server 与 Agent Skills 依赖清单采集、工具描述投毒（Tool Poisoning）检测、密钥外联审计与最小权限运行网关设计。

    AI 供应链 MCP Security · Agent Skills · OWASP ASI04
    规划中 ~20 min

CH 06溯源证明、平台扩展性与商业矩阵总装（SLSA & Enterprise Scale）

把单点检测升级为“防篡改溯源 + 秒级 0-day 全网定位 + 清晰商业差异化矩阵”的企业级供应链安全平台。

3 课 · 规模化收官
  • 0020
    构建溯源与密码学证明：SLSA v1.2、in-toto 与 Sigstore 闭环

    超越事后成分扫描：基于 SLSA v1.2 Build/Source Track 生成与验签 Provenance 和 VSA 证明，结合 Trusted Publishers 与 Sigstore 无密钥签名建立端到端防篡改信任链。

    全局架构 SLSA v1.2 · in-toto · Sigstore
    规划中 ~18 min
  • 0021
    企业级海量资产台账、全图谱检索与 0-day 秒级应急响应架构

    攻克数万项目、数亿依赖边下的冷热存储分层、组件去重归档、策略引擎热更新（OPA/CEL），实现 Log4Shell 级 0-day 爆发后 10 秒内定位全公司受影响应用与负责人。

    全局架构 图谱存储扩展 · 策略门禁 · 0-day 响应
    规划中 ~20 min
  • 0022
    总架构师收官实战：全场景 SCA 产品矩阵、研发配比与竞品攻防蓝图

    汇总全课程架构决策，制定你的 12 个月分阶段研发人力配比模型（底座维护 vs 壁垒攻坚）、商业化版本分层锚点与对标 Snyk/Endor/Socket/Wiz 的核心打法。

    总装收官 产品矩阵 · R&D 资源分配 · 商业壁垒
    规划中 ~20 min
